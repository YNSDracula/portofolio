YTOJEX Lokal

Order ojek & antar cepat untuk kota kamu. Mulai dari sistem sederhana — bisa berkembang jadi aplikasi.

Langkah cepat menjalankan:
  1. Pasang file ini di hosting atau buka di browser.
  2. Ubah nomor admin WhatsApp di script (lihat komentar).
  3. Promosikan via grup lokal / WA / FB.
  4. Rekrut 5 driver awal (WA grup).
Jika butuh, aku bisa bantu sesuaikan tampilannya (warna, logo, teks), atau ubah agar terhubung ke Google Forms / Google Sheets sebagai backup data.

Pengaturan penting (di script):

  • ADMIN_WHATSAPP: nomor admin untuk mengirim order
  • DEFAULT_COMMISSION_PERCENT: persentase komisi yang diharapkan
  • Tarif per km & minimum: bisa diubah di form
